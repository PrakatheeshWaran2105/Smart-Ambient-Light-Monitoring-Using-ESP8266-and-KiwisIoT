# Smart-Ambient-Light-Monitoring-Using-ESP8266-and-KiwisIoT
Smart Ambient Light Monitoring using NodeMCU ESP8266 and LDR sensor to measure surrounding light intensity and monitor real-time light levels through the KiwisIoT platform.
Smart Ambient Light Monitoring Using ESP8266 and KiwisIoT
About the Project
The Smart Ambient Light Monitoring System is designed to measure and monitor the light intensity in the surrounding environment. This project uses a NodeMCU ESP8266 and an LDR (Light Dependent Resistor) sensor to detect changes in ambient light levels.

The ESP8266 collects light intensity readings from the LDR sensor and transmits the data over Wi-Fi to the KiwisIoT platform. Users can monitor real-time light levels through the KiwisIoT dashboard, making it easy to observe changes in environmental lighting remotely.

This project demonstrates how IoT technology can be used for smart lighting applications, environmental monitoring, and real-time light intensity tracking.
